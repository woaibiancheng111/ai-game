# 隐私与日志说明模板

> 发布前请由发行主体、法务或项目负责人确认。本模板用于产品说明，不构成法律意见。

## 我们收集什么

默认桌面版采用本地优先存档。未启用 AI 代理、账号同步或遥测时，游戏数据主要保存在用户电脑的应用数据目录中。

可能涉及的数据类型：

- 玩家昵称、当前章节、选择记录、状态数值、成就和存档。
- 应用设置，例如音量、AI 开关、代理地址、日志开关。
- 错误日志，例如保存失败、AI 代理失败、启动异常、构建版本号。
- 如果启用 AI 代理，NPC 对话上下文会被发送到服务端代理，用于生成回复。

## 我们不应该收集什么

- 不在 Electron 客户端内置真实供应商 API Key。
- 不在日志中记录银行卡、身份证、密码、真实联系方式等敏感信息。
- 不上传本地存档，除非用户明确启用云同步或账号同步。
- 不默认采集聊天全文遥测；如确需采集，应单独告知并提供关闭方式。

## 本地数据位置

应用内设置页会显示：

- 数据目录：`userDataPath`
- 日志目录：`logsPath`

Windows 常见位置类似：

```text
C:\Users\<用户名>\AppData\Roaming\<应用名>\
```

## AI 代理说明

AI 对话增强通过服务端代理完成。客户端只请求代理地址，不保存真实供应商 Key。

当代理未配置、网络不可用、服务端超时或供应商失败时，游戏会自动使用静态剧情台词兜底，不影响主线游玩和存档。

服务端代理上线前应确认：

- 供应商 Key 只存在服务端环境变量或密钥管理系统中。
- 代理配置请求超时、并发限制、单用户频率限制和成本上限。
- 错误响应不返回供应商 Key、内部堆栈或敏感配置。
- 日志只记录必要错误码和请求元信息，避免长期保存完整对话。

## 用户权利与支持

建议向用户提供：

- 如何关闭 AI 对话增强。
- 如何关闭错误日志。
- 如何在设置页打开数据目录和日志目录。
- 如何在设置页导出日志包。
- 如何删除本地数据。
- 如何联系支持邮箱。

支持邮箱模板：

```text
support@example.com
```

用户反馈时建议提供：

- 应用版本号。
- Windows 版本。
- 问题发生时间。
- 错误截图或日志文件。

## 卸载与重装策略

需要在下载页或 FAQ 中明确：

- 卸载应用是否保留本地存档。
- 重装应用是否读取旧存档。
- 用户如何手动删除全部本地数据。
- 未来云同步上线后，云端数据如何删除。
