# Windows 商业版上线清单

本清单用于每次对外发布前确认。原则是：单机体验不依赖网络，AI 失败不断档，用户数据路径清楚，安装包可回溯。

## P0 发布阻断项

- [ ] 产品名、版本号、发行主体、支持邮箱、官网或下载页已确认。
- [ ] `package.json` 的 `version` 已递增，并与发布说明一致。
- [ ] `npm run typecheck` 通过。
- [ ] `npm run validate:story` 通过。
- [ ] `npm run route:smoke` 通过。
- [ ] `npm run test:e2e:smoke` 通过。
- [ ] `npm run dist:win` 成功生成 Windows 安装包。
- [ ] Windows 安装包完成代码签名，证书主体与发行主体一致。
- [ ] AI 代理地址、限流、超时、错误兜底、成本上限已在服务端配置。
- [ ] 未在客户端安装包、源码公开包、日志中包含真实供应商 Key。
- [ ] 隐私政策、用户协议、日志说明、数据删除路径已准备好。
- [ ] 离线、断网、无代理、代理 500、代理超时均可进入静态剧情兜底。

## P1 商业体验

- [ ] Windows 10 和 Windows 11 均完成冷启动、卸载、重装测试。
- [ ] 首次启动、继续游戏、手动存档、自动存档、读档恢复均通过。
- [ ] 升级安装后旧存档仍可读取，或已提供明确迁移/不兼容说明。
- [ ] 崩溃或错误日志路径可在设置页看到，客服能指导用户导出。
- [ ] 图标、字体、背景、立绘、BGM、音效均确认可商用。
- [ ] 教育、反诈、心理支持内容完成至少一轮人工审校。
- [ ] 主菜单、读档页、长对话、章节切换在低配机器上无明显卡顿。
- [ ] 安装包名称、桌面快捷方式、开始菜单名称、卸载条目一致。

## P2 上线运营

- [ ] 发布说明包含版本号、发布日期、主要改动、已知问题。
- [ ] 下载页提供 SHA256 校验值，方便用户确认安装包完整性。
- [ ] 支持邮箱或反馈表单可用，并能收集版本号、系统版本、日志文件。
- [ ] 如启用遥测，默认最小化采集并在隐私政策中说明。
- [ ] 如启用自动更新，已测试增量更新、失败回退和断网场景。
- [ ] 学校定制字段已整理：学校名、学院名、Logo、电话、官网链接、反诈提示。

## 发布后 24 小时观察

- [ ] 安装失败反馈数量。
- [ ] 启动失败或白屏反馈数量。
- [ ] AI 代理失败率和平均响应时延。
- [ ] 存档失败或读档失败反馈。
- [ ] 典型用户卡点：无法进入游戏、找不到继续游戏、设置误配。
